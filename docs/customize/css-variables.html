CSS variables

Use Bootstrap’s CSS custom properties for quick and forward-looking customization.

On this page
  • The :root variables
  • Component variables
  • Customizing a card

The :root variables #

Bootstrap exposes most of its Sass variables as CSS custom properties on :root. WindStrap keeps this layer intact — it’s how the translated classes stay themeable at runtime. See src/sections/root.css for the full list.

Color

--bs-primary #0d6efd

--bs-primary-rgb 13, 110, 253

--bs-body-color #212529

Typography

--bs-body-font-family

--bs-body-font-size 1rem

--bs-body-line-height 1.5

Borders & shadows

--bs-border-width 1px

--bs-border-radius 0.375rem

--bs-box-shadow

Component variables #

Most components also carry their own local variables on their base class. Override them on the element to customize it in place. A few examples from the translation:

ComponentKey variables
.btn--bs-btn-padding-x/y, --bs-btn-color, --bs-btn-bg, --bs-btn-border-color, --bs-btn-hover-*, --bs-btn-active-*
.card--bs-card-spacer-x/y, --bs-card-border-radius, --bs-card-bg, --bs-card-cap-bg
.alert--bs-alert-bg, --bs-alert-border-color, --bs-alert-color
.modal--bs-modal-width, --bs-modal-padding, --bs-modal-bg, --bs-modal-box-shadow
.dropdown-menu--bs-dropdown-min-width, --bs-dropdown-bg, --bs-dropdown-link-*
.accordion--bs-accordion-btn-icon, --bs-accordion-active-bg, --bs-accordion-active-color

Customizing a card #

Card header
Card body with custom border-radius, border-color and header background.
<div class="card"
     style="--bs-card-border-radius: 1rem; --bs-card-border-color: #6f42c1; --bs-card-cap-bg: #f1eafb;">
  <div class="card-header">Card header</div>
  <div class="card-body">Card body with custom border-radius, border-color and header background.</div>
</div>
