Color

Use our Sass maps to add new colors and modify existing ones.

On this page
  • All colors
  • Theme colors

All colors #

Bootstrap’s color system is available as Sass variables, maps, and CSS custom properties. WindStrap defines the same palette in tailwind.config.js so Tailwind utilities resolve to Bootstrap’s exact values, and keeps the --bs-* tokens in src/sections/root.css.

.border-primary

Theme colors #

The eight theme colors are defined once in tailwind.config.js and power the bg-*, text-*, border-* and text-bg-* classes: 

// tailwind.config.js
theme: {
  extend: {
    colors: {
      primary: '#0d6efd',
      secondary: '#6c757d',
      success: '#198754',
      info: '#0dcaf0',
      warning: '#ffc107',
      danger: '#dc3545',
      light: '#f8f9fa',
      dark: '#212529',
    },
  },
}

Adding new colors #

To add a custom color ($custom in Bootstrap), add it to the Tailwind theme and define its tokens in :root: 

/* tailwind.config.js */
colors: { custom: '#a6120d' }

/* src/sections/root.css */
:root {
  --bs-custom: #a6120d;
  --bs-custom-rgb: 166, 18, 13;
}

Then use it like any theme color: .bg-custom, .text-custom, .border-custom.
