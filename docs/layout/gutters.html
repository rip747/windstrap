Gutters

Gutters are the padding between columns.

On this page
  • Horizontal & vertical gutters
  • Row columns gutters
  • No gutters
  • Changing the gutter width in a column

Horizontal & vertical gutters #

Use .gx-* classes to control horizontal gutter widths, and .gy-* for vertical gutters. The .g-* shorthand sets both.

Custom column padding
Custom column padding
Custom column padding
Custom column padding
<div class="row gx-4 gy-2">
  <div class="col-6">Custom column padding</div>
  <div class="col-6">Custom column padding</div>
  <div class="col-6">Custom column padding</div>
  <div class="col-6">Custom column padding</div>
</div>

Row columns gutters #

Gutter classes can also be added to row columns.

<div class="row row-cols-2 row-cols-lg-5 g-2 g-lg-3">
  <div class="col">Row column</div>
  <div class="col">Row column</div>
  <div class="col">Row column</div>
  <div class="col">Row column</div>
  <div class="col">Row column</div>
</div>

No gutters #

The gutters between columns in our predefined grid classes can be removed with .g-0.

.col-sm-6 .col-md-8
.col-6 .col-md-4
<div class="row g-0">
  <div class="col-sm-6 col-md-8">.col-sm-6 .col-md-8</div>
  <div class="col-6 col-md-4">.col-6 .col-md-4</div>
</div>

Changing the gutter width in a column #

The horizontal and vertical gutters set on the .row use the --bs-gutter-x and --bs-gutter-y CSS variables. Override them on a column to change its gutters in place:

Default gutters
Custom gutter (.25rem)
<div class="row">
  <div class="col-6">Default gutters</div>
  <div class="col-6" style="--bs-gutter-x: .25rem;">Custom gutter (.25rem)</div>
</div>
