Grid

Bootstrap’s grid system uses a series of containers, rows, and columns.

On this page
  • How it works
  • Grid options
  • Row columns
  • Nesting

How it works #

Bootstrap’s grid system uses a series of containers, rows, and columns to layout and align content. It’s built with flexbox and is fully responsive. Below is an example and an in-depth look at how the grid comes together.

Column
Column
Column
<div class="container text-center">
  <div class="row">
    <div class="col">Column</div>
    <div class="col">Column</div>
    <div class="col">Column</div>
  </div>
</div>

The above example creates three equal-width columns on small, medium, large, and extra large devices using our predefined grid classes. Those columns are centered in the page with the parent .container.

Grid options #

Bootstrap’s grid system can adapt across all six default breakpoints, and any breakpoints you customize. The six default grid tiers are:

≥576px		 md
≥768px		 lg
≥992px		 xl

# of columns 12
Gutter width 1.5rem (0.75rem on each side of a column)
Custom gutters Yes
Nestable Yes
Column ordering Yes

Row columns #

Use the responsive .row-cols-* classes to quickly set the number of columns that best render your content and layout.

Column
Column
Column
Column
<div class="container text-center">
  <div class="row row-cols-2">
    <div class="col">Column</div>
    <div class="col">Column</div>
    <div class="col">Column</div>
    <div class="col">Column</div>
  </div>
</div>

Nesting #

To nest your content with the default grid, add a new .row and set of .col-sm-* columns within an existing .col-sm-* column.

Level 1: .col-sm-3
Level 1: .col-sm-9
Level 2: .col-8 .col-sm-6
Level 2: .col-4 .col-sm-6
<div class="row">
  <div class="col-sm-3">Level 1: .col-sm-3</div>
  <div class="col-sm-9">
    <div class="row">
      <div class="col-8 col-sm-6">Level 2: .col-8 .col-sm-6</div>
      <div class="col-4 col-sm-6">Level 2: .col-4 .col-sm-6</div>
    </div>
  </div>
</div>
