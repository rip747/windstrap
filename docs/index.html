What is translated?

Every rendered example uses the exact Bootstrap class names rebuilt from Tailwind utilities. Interactive behavior (dropdowns, modals, collapse, …) uses Bootstrap’s JavaScript bundle — the WindStrap translation covers the CSS layer.
