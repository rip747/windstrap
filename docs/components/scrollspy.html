Scrollspy

Automatically update Bootstrap navigation or list group components based on scroll position to indicate which link is currently active in the viewport.

On this page
  • Example in navbar
  • Example in list-group

Example in navbar #

Scroll the area below the navbar and watch the active class change. The dropdown items will be highlighted as well. To make this work, add data-bs-spy="scroll" to the scrollable element, plus data-bs-target="#navbar-example2", and give the nav links an id matching the scroll targets.
