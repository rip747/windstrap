Offcanvas

Build hidden toggleable sidebars into your project for navigation, shopping carts, and more.

On this page
  • Examples
    • Offcanvas components
    • Live demo
    • Placement
    • Backdrop
  • Dark offcanvas
  • Responsive

Examples #

Offcanvas is a sidebar component that can be toggled via JavaScript to appear from the left, right, top, or bottom edge of the viewport. Buttons with the data-bs-toggle="offcanvas" attribute control the visibility.

Offcanvas components #

Below is an offcanvas example that is shown by default (via .show on .offcanvas).

Offcanvas
Content for the offcanvas element. Place any content here. 
<div class="offcanvas offcanvas-start show" tabindex="-1" id="offcanvas" aria-labelledby="offcanvasLabel">
  <div class="offcanvas-header">
    <h5 class="offcanvas-title" id="offcanvasLabel">Offcanvas</h5>
    <button type="button" class="btn-close" data-bs-dismiss="offcanvas" aria-label="Close"></button>
  </div>
  <div class="offcanvas-body">
    Content for the offcanvas element. Place any content here.
  </div>
</div>

Live demo #

Use the buttons below to show and hide an offcanvas element via JavaScript.

Offcanvas

This is a live offcanvas demo — click the button to toggle it.

<button class="btn btn-primary" type="button" data-bs-toggle="offcanvas" data-bs-target="#demo" aria-controls="demo">
  Toggle offcanvas
</button>

<div class="offcanvas offcanvas-start" tabindex="-1" id="demo" aria-labelledby="demoLabel">
  <div class="offcanvas-header">
    <h5 class="offcanvas-title" id="demoLabel">Offcanvas</h5>
    <button type="button" class="btn-close" data-bs-dismiss="offcanvas" aria-label="Close"></button>
  </div>
  <div class="offcanvas-body">
    <p>This is a live offcanvas demo.</p>
  </div>
</div>

Backdrop #

Scrolling the <body> element is disabled when an offcanvas and its backdrop are visible. Use the data-bs-scroll attribute to toggle scrolling, and data-bs-backdrop to toggle the backdrop.

Enable body scrolling
…
Disable backdrop
…
<div class="offcanvas offcanvas-start" data-bs-scroll="true" data-bs-backdrop="false" tabindex="-1" id="enableBodyScrolling" aria-labelledby="enableBodyScrollingLabel">…</div>

Dark offcanvas #

Change the appearance of offcanvas components with utilities to better match them to different contexts.

Offcanvas dark

Place offcanvas content here with .text-bg-dark.

<div class="offcanvas offcanvas-start text-bg-dark" tabindex="-1" id="demoDark" aria-labelledby="demoDarkLabel">
  <div class="offcanvas-header">
    <h5 class="offcanvas-title" id="demoDarkLabel">Offcanvas dark</h5>
    <button type="button" class="btn-close btn-close-white" data-bs-dismiss="offcanvas" aria-label="Close"></button>
  </div>
  <div class="offcanvas-body">
    <p>Place offcanvas content here with <code>.text-bg-dark</code>.</p>
  </div>
</div>

Responsive #

Responsive offcanvas classes hide content outside of a given breakpoint: use .offcanvas-{sm|md|lg|xl|xxl} so the offcanvas becomes normal content above that breakpoint.

    <button type="button" class="btn-close" data-bs-dismiss="offcanvas" data-bs-target="#demoSm" aria-label="Close"></button>
  </div>
  <div class="offcanvas-body">…</div>
</div>
