Stretched link

Make any HTML element or Bootstrap component clickable by stretching a nested link.

On this page
  • Example

Example #

Add the .stretched-link class to a link to make its containing block clickable via a ::after pseudo-element. In most cases, this means an element with position: relative that contains a link with the .stretched-link class is clickable.

Card with stretched link

Some quick example text to build on the card title and make up the bulk of the card's content.

Go somewhere 
<div class="card" style="width: 18rem;">
  <img src="..." class="card-img-top" alt="...">
  <div class="card-body">
    <h5 class="card-title">Card with stretched link</h5>
    <p class="card-text">Some quick example text to build on the card title and make up the bulk of the card's content.</p>
    <a href="#" class="btn btn-primary stretched-link">Go somewhere</a>
