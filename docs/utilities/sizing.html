Sizing

Easily make an element as wide or as tall with our width and height utilities.

On this page
  • Width
  • Max width and height
  • Height

Width #

Set the width of an element with the w-* utilities.

Width 25%
Width 50%
Width 75%
Width 100%
Width auto
<div class="w-25 p-3 mb-2 bg-body-secondary border rounded-2">Width 25%</div>
<div class="w-50 p-3 mb-2 bg-body-secondary border rounded-2">Width 50%</div>
<div class="w-75 p-3 mb-2 bg-body-secondary border rounded-2">Width 75%</div>
<div class="w-100 p-3 mb-2 bg-body-secondary border rounded-2">Width 100%</div>
<div class="w-auto p-3 mb-2 bg-body-secondary border rounded-2">Width auto</div>

Max width and height #

Use mw-100, mh-100, and min-vw-100 to constrain the size of an element.

Max-width 100%
Max-height 100%
Min-width 100vw
Min-height 100vh
Width 100vw
Height 100vh
<div class="mw-100">Max-width 100%</div>
<div class="mh-100">Max-height 100%</div>
<div class="min-vw-100">Min-width 100vw</div>
<div class="min-vh-100">Min-height 100vh</div>
<div class="vw-100">Width 100vw</div>
<div class="vh-100">Height 100vh</div>

Height #

Set the height of an element with the h-* utilities.

Height 25%
Height 50%
Height 75%
Height 100%
Height auto
<div class="h-25 d-inline-block" style="width: 120px;">Height 25%</div>
<div class="h-50 d-inline-block" style="width: 120px;">Height 50%</div>
<div class="h-75 d-inline-block" style="width: 120px;">Height 75%</div>
<div class="h-100 d-inline-block" style="width: 120px;">Height 100%</div>
<div class="h-auto d-inline-block" style="width: 120px;">Height auto</div>
