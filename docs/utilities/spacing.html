Spacing

Assign responsive-friendly margin or padding values to an element.

On this page
  • Margin and padding
  • Horizontal centering
  • Negative margin
  • Gap

Margin and padding #

Assign responsive-friendly margin or padding values to an element with the m-* and p-* utilities. Spacing scale runs from 0 through 5, plus auto.

Centered element (mx-auto)
Margin end 2 (me-2) Margin start 3 (ms-3)
Padding y 2, x 4 (py-2 px-4)
<div class="mx-auto" style="width: 200px;">Centered element</div>
<span class="me-2">Margin end 2</span>
<span class="ms-3">Margin start 3</span>
<div class="py-2 px-4">Padding y 2, x 4</div>

Horizontal centering #

Use .mx-auto to horizontally center block-level content.

Centered element
<div class="mx-auto p-3" style="width: 200px;">Centered element</div>

Negative margin #

Negative margin utilities are prefixed with n.

Negative margin (mx-n5)
<div class="mx-n5">Negative margin</div>

Gap #

Use the gap-* utilities to control the space between flex or grid items.

Gap item
Gap item
<div class="d-flex gap-3">
  <div class="p-2">Gap item</div>
  <div class="p-2">Gap item</div>
  <div class="p-2">Gap item</div>
</div>
