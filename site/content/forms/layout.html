Forms with grid #

Use the Bootstrap grid to lay out form controls side by side. Wrap form controls in columns (.col-*) inside a .row with gutters (.g-3).

Horizontal form #

Create horizontal forms with the grid by adding the .row class to form groups and using the .col-*-* classes to specify the width of your labels and controls. Be sure to add the .col-form-label class to your <label>s as well so they’re vertically centered with their associated form controls.

Inline forms #

Use the d-flex display utility (or row-cols-*) and align-items-* utilities to create horizontal inline forms.

Gutters #

With the grid, you can control the amount of space between columns with the g-* classes. For tighter form layouts, use a smaller gutter.
