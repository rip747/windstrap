Example #

Textual form controls—like <input>s, <select>s, and <textarea>s—are styled with the .form-control class. Included are support for all of Bootstrap’s form control styles, along with some custom styling.

Sizing #

Set heights using classes like .form-control-lg and .form-control-sm.

Plaintext #

If you want to have your <input readonly> elements in your form styled as plain text, replace .form-control with .form-control-plaintext.

File input #

Color #

Set the type="color" on an input to use the color picker.
