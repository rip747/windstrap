Checks #

Native checkbox and radio inputs are recreated with .form-check-input and paired with .form-check-label.

Radios #

Disabled #

Add the disabled attribute and the associated <label>s are automatically styled to match with a lighter color.

Switches #

A switch has the markup of a custom checkbox but uses the .form-switch class to render a toggle switch.

Inline #

Group checkboxes or radios on the same horizontal row by adding .form-check-inline to any .form-check.

Without labels #

Omit the <label> (or hide it with the .visually-hidden class) — remember to still provide an accessible name via aria-label.

Toggle buttons #

Create button-like checkboxes and radio buttons by using .btn-check styles with the .btn styles.
