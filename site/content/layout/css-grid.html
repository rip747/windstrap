How it works #

Bootstrap’s grid system can be used with the native CSS Grid by adding the .d-grid display utility and using the .gap-* spacing utilities (and optionally the .col-* classes for sizing columns).

grid-column: 1
grid-column: 2 (spans twice as wide)

Changing the layout #

CSS Grid allows for much more granular control than the flexbox grid. You can use any of the standard grid CSS properties with the .d-grid utility and the responsive display variants (.d-md-grid, etc.).
