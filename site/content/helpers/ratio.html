About #

Use the .ratio helper to create a responsive media container with a fixed aspect ratio. Wrap any embedded content (like an <iframe>, <img>, or <video>) in an element with the .ratio class and a ratio modifier class.

Ratios can be customized with modifier classes.

Custom ratios #

Each .ratio-* class includes a CSS custom property (or CSS variable) in the selector. You can override this variable to create custom aspect ratios.
