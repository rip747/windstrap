File structure #

Bootstrap ships its styles as Sass in scss/. WindStrap ships the compiled result as Tailwind-@apply CSS, organized to mirror the same logical structure: 


WindStrap/
├─ tailwind.config.js        # theme: screens, colors, fonts (≈ scss/_variables.scss)
├─ src/
│  ├─ windstrap.css          # entry point  (≈ bootstrap.scss)
│  └─ sections/
│     ├─ root.css            # tokens + reboot (≈ _root.scss, _reboot.scss)
│     ├─ layout.css          # containers & rows (≈ _grid.scss)
│     ├─ content.css         # typography, tables (≈ _type.scss, _tables.scss)
│     ├─ forms.css           # form controls (≈ _forms.scss)
│     ├─ buttons.css         # buttons & groups (≈ _buttons.scss)
│     ├─ nav.css             # nav & navbar (≈ _nav.scss, _navbar.scss)
│     ├─ components.css      # cards, alerts, list-groups, … (≈ _cards.scss …)
│     ├─ overlays.css        # modal, tooltip, carousel, … (≈ _modal.scss …)
│     └─ helpers.css         # text-bg, links, ratio, … (≈ _helpers.scss)
│  └─ generated/             # grid, utilities, responsive variants
└─ dist/windstrap.css        # compiled output

Variables #

Bootstrap assigns values to CSS variables from its Sass variables, e.g. $primary becomes --bs-primary in :root. WindStrap keeps those variables verbatim in src/sections/root.css, so any customization you’d do with Sass variables is expressed directly on the CSS custom properties: 


/* Bootstrap Sass */
$primary: #0d6efd;

/* WindStrap CSS variable (src/sections/root.css) */
:root {
  --bs-primary: #0d6efd;
  --bs-primary-rgb: 13, 110, 253;
}

Maps, loops & mixins #

Sass features that generate classes at compile time are replaced in WindStrap by the Tailwind theme and by our generator:

Bootstrap SassWindStrap equivalent
@each $color, $value in $theme-colors (button/alert/text/bg loops)theme.extend.colors in tailwind.config.js + @apply bg-primary, @apply text-primary…
$grid-breakpoints maptheme.screens
@include media-breakpoint-up(md)Tailwind variants (md:, lg:…) in @apply
@mixin button-variant()Explicit @apply bg-primary hover:bg-[…] active:bg-[…] in src/sections/buttons.css
Utility generator ($utilities map)scripts/generate-utilities.js emits the same classes via @apply

Customizing in practice #

Where Bootstrap recompiles Sass, WindStrap edits the @apply source. For example, to make primary buttons use a purple: 


/* src/sections/buttons.css */
.btn-primary {
  @apply bg-[#6f42c1] text-white border-[#6f42c1]
    hover:bg-[#5a32a3] hover:border-[#5430a0]
    active:bg-[#5430a0] active:border-[#4e2d92];
}
