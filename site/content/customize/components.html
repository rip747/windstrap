Per-component customization #

Every WindStrap component keeps Bootstrap’s local CSS variables on its class, so the same per-component customization Bootstrap supports works at runtime. For example, the button component exposes --bs-btn-* variables that you can override without touching the source.

Editing the source #

For compile-time changes, edit the @apply translations in src/sections/. The component files map to Bootstrap’s component styles:

ComponentFile
Buttons & button groupssrc/sections/buttons.css
Nav & navbarsrc/sections/nav.css
Cards, alerts, list-groups, dropdowns, accordion…src/sections/components.css
Modal, tooltip, popover, carousel, spinner, offcanvas…src/sections/overlays.css
Formssrc/sections/forms.css
Helpers & utilitiessrc/sections/helpers.css, scripts/generate-utilities.js

Each rule reads like Bootstrap’s final CSS, but composed from Tailwind utilities: 


/* src/sections/buttons.css — .btn-primary */
.btn-primary {
  @apply bg-primary text-white border-primary
    hover:bg-[#0b5ed7] hover:border-[#0a58ca]
    active:bg-[#0a58ca] active:border-[#0a53be]
    active:shadow-[inset_0_3px_5px_rgba(0,0,0,0.125)];
  --bs-btn-focus-shadow-rgb: 49, 132, 253;
}
