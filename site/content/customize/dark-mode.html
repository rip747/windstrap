How it works #

Bootstrap 5.3 supports dark mode through the data-bs-theme="dark" attribute on the root <html> element. WindStrap keeps this exact mechanism — the dark-mode token overrides live in src/sections/root.css.

Customizing #

The dark palette is defined by the [data-bs-theme="dark"] block in src/sections/root.css. Override any token to change it: 


[data-bs-theme="dark"] {
  --bs-body-bg: #1a1d20;       /* page background */
  --bs-body-color: #dee2e6;    /* page text */
  --bs-primary: #6ea8fe;       /* primary accent */
  --bs-primary-rgb: 110, 168, 254;
}
