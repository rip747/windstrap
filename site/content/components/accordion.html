Variables #

WindStrap keeps Bootstrap’s local CSS variables on the accordion components, so the same real-time customization works: --bs-accordion-btn-icon, --bs-accordion-btn-icon-width, --bs-accordion-btn-icon-transform, --bs-accordion-btn-icon-transition, --bs-accordion-active-color, --bs-accordion-active-bg, etc. are defined in src/sections/components.css.
