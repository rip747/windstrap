Variables #

WindStrap keeps Bootstrap’s local CSS variables on .modal — --bs-modal-width, --bs-modal-padding, --bs-modal-margin, --bs-modal-bg, --bs-modal-border-radius, --bs-modal-box-shadow, --bs-modal-header-*, --bs-modal-footer-* — defined in src/sections/overlays.css.
