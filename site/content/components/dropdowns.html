Overview #

Dropdowns are toggleable, contextual overlays for displaying lists of links and more. They’re made interactive with the included Bootstrap dropdown plugin and are triggered by clicking, not by hovering.

Requires the dropdown plugin

The data-bs-toggle="dropdown" behavior is driven by Bootstrap’s JavaScript dropdown plugin, included on these pages via the JS bundle.
