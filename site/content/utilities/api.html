How it works #

The Bootstrap utility API is a Sass-based tool to generate utility classes. In WindStrap, those utility classes are rebuilt as Tailwind CSS rules via @apply, giving you the same class names and behavior.

All Bootstrap utility classes — like .m-*, .p-*, .d-*, .text-*, .bg-*, and the responsive d-sm-flex / mt-lg-3 variants — are available with the exact Bootstrap naming, generated in src/generated/.

Customizing the utilities

Because WindStrap maps Bootstrap utilities onto Tailwind, you can also use Tailwind’s own @apply in your markup if you prefer. But the docs here always show the Bootstrap class names for a one-to-one translation.
