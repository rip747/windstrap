Responsive images #

Images in Bootstrap are made responsive with .img-fluid. This applies max-width: 100% and height: auto so the image scales with the parent width.

Image thumbnails #

In addition to our border-radius utilities, you can use .img-thumbnail to give an image a rounded 1px border appearance.

Aligning images #

Align images with the float utility classes or text alignment classes.

Picture #

If you are using the <picture> element to specify multiple <source> elements for a specific <img>, make sure to add the .img-fluid class to the <img> and <source> elements.
