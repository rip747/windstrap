Approach #

Reboot builds on Normalize, providing only the element-specific CSS that Bootstrap needs. WindStrap carries the same reboot rules in src/sections/root.css, so the base element styles match Bootstrap exactly.

Headings #

All heading elements (<h1>–<h6>) are unstyled except for their size, weight, and line-height. Their default styles are reset to a consistent look with the .h1–.h6 classes.

Body #

The <body> is reset to use the font stack, size, line-height, and text/background colors from the --bs-body-* tokens.

Links #

Links are styled with the --bs-link-color and --bs-link-hover-color tokens, and are underlined by default.

This is a link, hover it.

Horizontal rules #

The <hr> element is reset to use the border width from --bs-border-width, is slightly transparent, and stacks.

Lists #

Lists (and nested lists) are reset to remove default margins and padding, and <ol>/<ul> receive a default padding-left.

  • All lists have their top margin removed
  • And their bottom margin normalized
  • Nested lists have no bottom margin
    • This way they have a more even appearance
  1. Ordered lists are still properly numbered

Tables #

Tables are adjusted to inherit border-color, use border-collapse: collapse, and place captions at the bottom.

Forms #

The <fieldset>, <legend>, <input>, <button>, <select>, <optgroup>, and <textarea> elements are reset to inherit font styles and margin; textarea only resizes vertically.
