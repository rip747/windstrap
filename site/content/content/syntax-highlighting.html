How it works #

Bootstrap’s documentation uses highlight.js to colorize the code samples you see on these pages. It’s applied after the page renders, so the same approach works here.

Custom styles #

On these pages, code blocks are styled with the .highlight class from docs/css/docs.css. You can restyle them however you like — the token colors (.hl, .attr, .str, …) are defined there and can be overridden.
